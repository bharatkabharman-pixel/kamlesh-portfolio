Overview

Event check-in, fast and reliable

EPASES is a purpose-built tool for event organizers to manage attendees and validate tickets on the spot. Organizers get a full view of their events and attendee lists pulled from a REST API, while staff at the door can scan QR codes in seconds — making check-in smooth and stress-free even at busy events.

I built the EPASES mobile app in Flutter using Provider for clean state management and REST APIs for live data — delivering a responsive, intuitive experience on both iOS and Android from a single codebase.

The Challenge & Goals

The Challenge

Event organizers often rely on printed guest lists, spreadsheets or generic QR scanner apps that aren't built for the job. Entry queues pile up, attendees get missed, and there's no live view of who's checked in. The goal was a dedicated tool that makes ticket validation instant and attendee management effortless.

The Goals

  • Fast QR ticket scanning at event entry
  • REST-driven event & attendee list sync
  • Real-time check-in tracking
  • Intuitive UI for non-technical event staff
  • Consistent experience on iOS & Android
Key Features

What EPASES does

QR Ticket Scanner

Instant camera-based QR scanning to validate tickets at entry — fast, accurate and offline-friendly.

Event Management

Browse all events pulled live from the REST API — with dates, venue details and attendee counts at a glance.

Attendee Lists

Full attendee roster per event, fetched via REST — with names, ticket types and check-in status.

Real-time Check-in

Mark attendees as checked in instantly — status updates sync live so all devices stay in sync.

Attendee Search

Search the attendee list by name or ticket ID to quickly find and check in specific guests.

Push Notifications

Firebase-powered alerts to keep organizers updated on event activity and entry milestones.

Tech & Architecture

How it's built

EPASES is built in Flutter for a smooth, consistent experience across iOS and Android. Provider manages app state cleanly — keeping the UI reactive to scan results and check-in updates without unnecessary rebuilds. Event and attendee data is fetched and synced via a REST API, while Firebase handles authentication and push notifications. The QR scanner is optimised for speed, giving near-instant feedback on each scan.
